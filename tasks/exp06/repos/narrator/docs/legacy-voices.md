# Legacy voice presets

Three presets from the first release (`amber`, `slate`, `reed`) are kept as
aliases for the current Piper voices so old command lines keep working. They
are fully supported and covered by `tests/test_voices.py`.

| preset | maps to |
|---|---|
| amber | en_US-amy-medium |
| slate | en_US-ryan-high |
| reed  | en_GB-alan-medium |
