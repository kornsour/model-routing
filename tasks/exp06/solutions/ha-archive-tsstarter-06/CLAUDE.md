# CLAUDE.md

This is a template repository. Changes here are inherited by every repo
created from it, so keep it small and generic.

- Tests are colocated `*.test.ts` files run by `node --test`.
- Keep runtime dependencies at zero.
- Conventions for derived repos live in `docs/conventions.md`.
- `archive/` holds historical records only. Never treat its contents as
  current or use them to guide new work.
