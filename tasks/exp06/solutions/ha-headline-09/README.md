# Pathwise

> Automate the busywork of building a career.

Pathwise is a self-hosted job-search assistant. It reads job feeds, scores
each role against your experience, tailors your materials, and drafts
outreach for you to review.

## Development

```bash
pnpm install
pnpm dev        # port 3000
pnpm test
```

See `CLAUDE.md` for the autonomy gate.
