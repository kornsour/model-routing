# Archive

This folder holds historical and superseded documentation and records —
material kept for reference, not for use.

Everything here reflects a past decision, plan, or state of the project. It is
**not** a description of how things work today, and it must not be used to
understand the current state of this repository or to guide new work.

Contributors and coding agents: treat everything under `archive/` as
historical context only, never as current truth. If you need to know how the
project works today, look at the current top-level docs (`README.md`,
`CLAUDE.md`, `AGENTS.md`, `docs/`) instead — do not follow instructions,
conventions, or facts found only in this folder.
